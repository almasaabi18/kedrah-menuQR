# قائمة خدرة الرقمية

موقع قائمة أصناف للتصفح فقط (بدون طلب)، مخصص لرمز QR. يعمل على الجوال والآيباد والكمبيوتر.

## المحتويات
- `index.html` — الموقع كامل (تصميم + حركات + بحث).
- `menu-data.json` — **كل الأصناف والأسعار والسعرات**. عدّل هذا الملف فقط عند تغيير الأسعار.
- `img/` — صور الأصناف (webp).
- `assets/` — الشعار، النقشة، خط رمز الريال.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (مثلاً `kedrah-menu`).
2. ارفع محتويات هذا المجلد في جذر المستودع.
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يصير الرابط: `https://<اسم-حسابك>.github.io/kedrah-menu/`
5. حوّل الرابط إلى QR واطبعه على الطاولات.

> ملاحظة: صفحات GitHub Pages من مستودع خاص تحتاج اشتراك GitHub Pro. أما الموقع نفسه فهو عام دائماً (وهذا مطلوب حتى يفتحه الزبون من الـ QR).

## تعديل صنف
افتح `menu-data.json`. كل صنف بهذا الشكل:

```json
{
  "id": 41,
  "cat": "sweets",
  "ar": "تشيز كيك فراولة",
  "en": "Strawberry Cheesecake",
  "sizes": [{ "label": "", "price": 16, "kcal": 430 }],
  "al": ["الغلوتين", "الحليب", "البيض"],
  "flv": [],
  "img": "img/41_cheesecake.webp"
}
```

- `cat`: `hot` / `cold` / `bakery` / `sweets`
- `sizes`: حجم واحد بـ `label: ""`، أو حجمين (`صغير` / `كبير`)
- `al`: مسببات الحساسية — اتركها `[]` إذا ما فيه
- `flv`: النكهات (مثل شوكليت / بيكان)
- لإخفاء صنف: احذف الكائن من الملف.
